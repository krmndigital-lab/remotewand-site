Remote Wand Desktop

Free companion for Windows · lets the Remote Wand app control your PC over Wi-Fi

Install this small program on your PC, open Remote Wand on your phone, choose Add device → Wi-Fi and enter the 6-digit code shown by the program. From then on your phone is a trackpad, keyboard, media remote and power button for the PC. No internet connection is used; the link stays on your Wi-Fi and is encrypted.

Download

Windows 10 / 11 (64-bit) — ZIP

Unzip and run remote-wand-desktop.exe. Windows SmartScreen may warn about an unknown publisher the first time: choose "More info → Run anyway". The program is not signed with a paid certificate.

macOS and Linux builds: planned.

Features

  • Trackpad with two-finger scrolling and right click, keyboard with special keys and function keys, unicode text in any language.
  • Media keys and volume, presentation keys (next / previous slide, black screen).
  • Lock, sleep, restart and shut down from your phone (each asks for confirmation).
  • Pairing with a 6-digit PIN; the connection is encrypted (X25519, ChaCha20-Poly1305). Paired phones can be forgotten at any time.
  • Runs in the system tray; can start with Windows.

Requirements

Phone and PC on the same local network. Remote Wand Pro on the phone (PC control over Wi-Fi is a Pro feature; the Bluetooth keyboard/mouse mode works without the desktop program and without Pro).

Firewall

The program listens on TCP port 47101 and announces itself with mDNS (Bonjour-style) on your local network. Windows asks once to allow it on private networks; choose "Allow".
